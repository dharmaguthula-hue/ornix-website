# ORNIX Cinematic Website

Premium Next.js App Router experience for ORNIX with:

- Dark luxury visual system
- Interactive hero `X` portal with lightweight Three.js scene
- Motion-driven section transitions using Framer Motion
- Featured products, crafted layers, customization preview, reel process, gallery, CTA
- Optimized image usage via `next/image`

## Run

```bash
npm install
npm run dev
```

## Notes

- Product images are in `public/images/products`.
- Ambient toggle expects `public/ambient.mp3` if you want background sound.
